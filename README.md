# Jamie Fitness trainer onboarding

Public handbook plus the current V2 software films.

Open the site: **https://jamie185.github.io/jf-trainer-onboarding/**

- Training path: the full handbook (welcome, tools, selling, coaching, standards)
- Software films: the 15 current JF Coach and Trainer Portal walkthroughs, also wired into the matching lessons
- Film player: `films.html` plays the 15 films in order

These films use demo names only. They do not send, charge, publish, or book a live session.

## Local

Open `index.html` in a browser, or:

```
python -m http.server 8765
```

Then visit http://127.0.0.1:8765/

## What is in here

The July 2026 trainer handbook, with September 2026 V2 software films replacing the old software clips. Coaching craft videos (Count Cue Encourage, session intensity, professionalism) stay as they were.

No passwords, pairing codes, or live-client files are in this repo.
